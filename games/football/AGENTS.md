# Football: agent rules

For work inside `games/football/`, these rules add to the repo-wide `AGENTS.md` and `CODING_STANDARDS.md`.

- **Design and tickets:** `GDD.md` describes the game as built. Read it before changing gameplay, and update it when
  a change alters what it says. Open tickets are in `issues/`. The original plan and its phase tickets are in the
  history of PR #55.
- **Assets** live in `games/football/assets/` and resolve at the same paths as the shared root `assets/` (for
  example `data/plays/`, `textures/field.png`). Put new football assets there, not in the root.
