# 14: Audio

Spec: [spec](../spec.md). Read: [Presentation](../spec/presentation.md) (audio).

**What to build:** The game gets sound. Free, redistributable SFX for claw snap, bubble pop, crest, molt and the boss
(as those features exist), plus one music loop, are loaded through the assets module from the game's own assets. In the
browser, audio starts after the first click or key press. A credits file lists every asset with its source and
licence.

**Blocked by:** 02 (Core loop).

**Status:** done

- [x] Music loops during the run.
- [x] Claw snaps make a sound, and each later sound (pop, crest, molt, boss) is wired as its feature lands.
- [ ] In the WASM build, audio starts after the first input and doesn't error before it. (Deferred to the end-of-jam WASM pass.)
- [x] Every asset's source and licence is in the credits file, and each licence allows redistribution.
- [x] Checked on desktop through the Remote API (music entity plays and unloads with the scene, sound bank loaded); the browser check is deferred to the WASM pass. Listening by ear is still to do.

## Decisions

Settled 2026-10-24.

- **This ticket needs a small engine change, and that's allowed.** The platform has `LoadSound`/`PlaySound` only, and
  `engine::audio::Music` says "playback wiring beyond one-shot sounds is future work". Add music streaming to the
  platform interface (`LoadMusic`, `UnloadMusic`, `PlayMusic`, `StopMusic`, `UpdateMusic`, `SetMusicVolume`, backed
  by raylib's `LoadMusicStream`/`UpdateMusicStream`, with no-ops in the null platform). Add a `MusicPlayback` system
  in the audio module that streams `Music` entities and loops them. Follow `CODING_STANDARDS.md` for that engine
  part, and update `src/engine/audio/README.md`.
- **Music behaviour.** The arena scene owns a `Music` entity, so it starts with a run and stops when the scene
  unloads. It keeps playing during molt, pause and results. Title is silent.
- **SFX source: generate them.** A committed script `games/crabnado/tools/make_sfx.py` (Python stdlib only: `wave`,
  `math`, `random`) writes short WAVs (claw snap, bubble pop, crest whoosh, molt chime, boss slam, rogue warning).
  They're our own work, so the licence is CC0 and there's no download or licence risk. Wire each SFX only if its
  feature has landed.
- **Music source.** One CC0 loop (OGG, under about 2 MB) from Kenney (kenney.nl) or OpenGameArt with the CC0 filter,
  with the URL recorded. If the implementer has no web access, stop and ask the user for the file. Don't generate
  music.
- **Files.** `assets/audio/crabnado/`. Credits go in `games/crabnado/CREDITS.md` (asset, source URL or "generated by
  tools/make_sfx.py", licence).
- **Crest sound.** Play it when a **big** crest reaches the player, not every crest. Use the same timing as the
  telegraph.
- **Browser audio unlock** is deferred to the end-of-jam WASM pass (raylib/miniaudio resumes the AudioContext on the
  first input, and the title's Play click counts).

## Comments

- Music is "Underwater" by Cleyton Kauffman (CC0, listed as looped), the OGG at 2.4 MB, slightly over the 2 MB guide.
- The default UI button click is now a generated two-tick `claw_click.wav` (`LoadSfx` calls `SetDefaultClickSound`).
- Crest cue plays once when a big crest comes within `kBigCrestWarning`, the same moment as the telegraph. The rogue warning plays when a rogue spawns.
